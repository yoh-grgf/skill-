# 交付前自检清单

逐条写结论（通过 / 不通过 + 证据）。不通过的不许交付。

## 一、视觉

- [ ] 全站只有一个强调色；主色饱和度 45–65%
- [ ] 圆角档位 ≤ 3 种，且与令牌一致
- [ ] 阴影 ≤ 2 档；暗色模式不用黑影
- [ ] 间距全部落在 8pt 刻度上（抽查 10 处）
- [ ] 字号阶梯 ≤ 6 级；正文行高 1.5–1.75（中文 1.6–1.8）
- [ ] 标题层级 h1 唯一，h2/h3 不跳级
- [ ] 没有纯 `#000` 文字压在纯 `#FFF` 上（用近黑/近白）
- [ ] 空状态、加载态、错误态都有样式（不是空白页）

## 二、交互

- [ ] 所有可点元素有 hover / active 反馈，时长走令牌（120–320ms）
- [ ] `focus-visible` 有可见轮廓（不许 `outline: none` 了事）
- [ ] 表单校验有就地提示，不是 alert
- [ ] 移动端点击区域 ≥ 44×44px
- [ ] 页面滚动时导航不遮挡内容锚点
- [ ] `prefers-reduced-motion` 下动效降级

## 三、无障碍

- [ ] 正文对比度 ≥ 4.5:1，大标题 ≥ 3:1（给出实测值）
- [ ] 暗色模式同样达标（两套都要测）
- [ ] 全部图片有 `alt`；装饰性图 `alt=""`
- [ ] 语义标签：`header/nav/main/section/footer`，不拿 div 当按钮
- [ ] 键盘 Tab 能走完主流程，焦点顺序与视觉顺序一致
- [ ] 表单 label 与控件关联（`for`/`aria-label`）

## 四、工程

- [ ] 单文件可运行 / 或依赖锁死；双击能开
- [ ] 无外链图片（或已本地化），断网不白屏
- [ ] 样式无 `!important` 滥用；无魔法数字
- [ ] 令牌为唯一真源：改 `design-tokens.json` 能整体换肤
- [ ] 三种断点（≤640 / ≤1024 / ≥1280）都不溢出横向滚动
- [ ] 控制台无报错与警告

## 五、一致性（多页面项目必查）

- [ ] 第 1 页与最后一页的按钮、卡片、间距是同一套
- [ ] 链接 hover / 高亮效果全站一致
- [ ] 图标全部来自同一图标库，线宽一致
- [ ] 同一层级标题字号一致（不允许「这页大一号」）
